## 一、GPT 裁决 1 落地：回执补「也不会自动重试」

GPT 裁决原文：

> 建议未来改成：「为避免重复执行或漏发，本次没有继续发送命令，**也不会自动重试**。」
> 这样和 `unknown / inferred_success / dispatched_unconfirmed` 的既有回执口径完全一致，
> 也能防止用户误以为后台任务还会继续。

落地后完整回执（`core/workflow.py` L865-869）：

```text
工作流已暂停：内部执行状态异常，无法安全确认命令对应关系。
（命令与执行报告数量不一致：2 条命令 / 1 份报告）
为避免重复执行或漏发，本次没有继续发送命令，也不会自动重试。
请先在游戏内确认实际结果，再决定是否重新发起；若持续出现，请反馈此提示。
```

四句话各自守住的语义（逐句核对）：

| 句子 | 作用 |
| --- | --- |
| 工作流已暂停：内部执行状态异常，无法安全确认命令对应关系。 | 定性：为什么停（内部结构异常，不是服务器问题） |
| （原因原文） | 不吞事实，可追溯 |
| 为避免重复执行或漏发，本次没有继续发送命令，也不会自动重试。 | **风险 + 事实 + 机制承诺**（本句为本次新增承诺） |
| 请先在游戏内确认实际结果，再决定是否重新发起；若持续出现，请反馈此提示。 | 行动指引 + 反馈出口 |

## 三、GPT「额外发现」落地：数值计算补**确定性**路由守门（本版核心）

GPT 的提醒：

> **提示词增强 ≠ 硬路由保证。** 当前「附魔/NBT/组件」等有代码守门，
> 但「数值计算」主要依赖分类器 prompt。
> 如果想让它成为硬保证，下一版应把「数值计算、配比、产量、耗材、材料需求」加入确定性路由特征。

### 落地

`core/command_result.py` 新增常量与函数，并接入既有第一层路由信号：

```python
_COMPLEX_NUMERIC_MARKERS = (
    "数值计算", "配比", "产量", "耗材", "材料需求", "需要多少",
    "每分钟", "每秒产出", "机器效率",
)


def looks_like_numeric_request(request: str) -> bool:
    """请求是否属于「数值计算」类（v0.22.11，**确定性**守门）。…"""
    low = (request or "").lower()
    return any(m in low for m in _COMPLEX_NUMERIC_MARKERS)


def looks_like_complex_request(request: str) -> bool:
    """用户请求文本是否命中复杂特征（第一层路由信号）。"""
    low = (request or "").lower()
    return looks_like_numeric_request(low) or any(m in low for m in _COMPLEX_REQUEST_MARKERS)
```

守门位置不变（`core/workflow.py` L126）：分类出 `simple` 之后、执行之前
`looks_like_complex_task()` 命中即**强制转 complex**，日志如实记录可追溯。
**只升级、不降级**。

## 七、自曝取舍（含本版新增）

**取舍 9｜数值守门关键词的宽窄（本版最值得挑的一条）。**
选了 9 个词：`数值计算 / 配比 / 产量 / 耗材 / 材料需求 / 需要多少 / 每分钟 / 每秒产出 / 机器效率`。
- 偏窄的风险：漏掉口语说法（`多少组`、`够不够`、`要几个`）→ 仍可能落到 simple。
- 偏宽的风险：`需要多少` 这类词可能把「我还需要多少经验升级」误升级为 complex（慢，但安全）。
皮莉卡选择**宁宽勿漏**并**故意不收录**「几个 / 多少个」这种高误伤词（普通查询会被白烧 token）。
请 GPT 判：这 9 个词是否够？要不要再加/再删？

**取舍 10｜本守门是否应该做成可配置（WebUI 开关）。**
现在硬编码在 `command_result.py`。好处是「确定性」名副其实；坏处是用户无法按自己整合包调整关键词。
若 GPT 认为该可配置，皮莉卡建议做成「追加关键词」而非「替换清单」（保留默认兜底）。

**取舍 11｜`looks_like_numeric_request()` 单独成函数。**
为了可测试与可回退（将来若要撤销这条守门，只需让 `looks_like_complex_request()` 不再调用它）。
代价是模块多了一个公开函数。

**取舍 1~8（上一单已交底，状态更新）**：1 已按 GPT 裁决**保留**（行动指引）；
2 已按裁决**补上**「也不会自动重试」；3 已按裁决保留并**追加确定性守门**（取舍 9/10）；
4 已按裁决**不改**（权限举例句）；5 已按裁决**保留**；6 已按裁决**统一**；
7 已按裁决**全量重跑**（UI 10/10）；8 本版已按主人指令发**预发布**（见第九节）。
