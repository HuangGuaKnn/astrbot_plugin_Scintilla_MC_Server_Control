## 明确不做

| 项 | 为什么不做 |
| --- | --- |
| 数字物品 ID 反查 | 1.13 之前的老 ID 表与 mod 冲突严重，误判的代价高于收益 |
| 同时对接多个 RCON 目标（多后端矩阵） | **难度过大**：不是配置多几项的问题 —— 每个后端都要独立判定世代、独立维护连接与重连、独立处理命令语法差异，出错时的归因成本成倍上升；投入产出比不成立 |
| 向非管理员开放 WebUI 命令执行 | RCON 具备服务端控制权限 |
| 玩家背包 / 物品栏读写 | 不属于「服务器管控」的范畴，且各模组写法互不兼容 |
