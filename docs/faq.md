# 常见问题

[返回 README](../README.md) · [界面效果](gallery.md) · [配置详解](configure.md) · [使用指南](usage.md)

安装与使用中容易踩到的坑。

### 1. 工具都说「物品词典不可用」？

服务端目录没配好。到 WebUI「设置」页填 `server_dir` 并保存 —— 保存即重算指纹与词典，不用重载插件。

### 2. 换了服务端，知识库会自己切吗？

不会。指纹变化时插件只在 WebUI 弹全屏提醒并高亮不匹配的预设，是否搬家由你确认（预设支持复制 / 移动 / 绑定到本服务端）。

### 3. AstrBot 和服务端不同机？

打开「异地 RCON 模式」：只走 RCON，依赖本地文件的功能（物品词典、知识库、事件播报、版本探测、进程指标）全部按设计禁用，并在界面上写明原因。

### 4. 能控制基岩版 / 代理端吗？

只走 RCON 的标准能力。凡是不经 RCON 的功能（日志播报、词典、指纹）都要求能读到服务端目录。

### 5. 为什么内存 / CPU 显示不出来？

这两项依赖 `psutil`，缺失时插件会自动降级（不报错，只是不显示）。装一下即可：`pip install psutil`。

### 6. 停用某个工具后 AI 还看得见它吗？

部分工具（如 `mc_workflow`）模型仍会看到，但调用时会收到导航提示，转而使用其他工具，不会真的执行。

### 7. `mcs` 前缀和 AstrBot 唤醒词冲突？

指令组的前缀跟随 AstrBot 的唤醒词设置。若你把唤醒词改成了别的，指令也相应变化。

### 8. 能同时接多个服务端吗？

一个插件实例目前只能连一个 RCON 目标。需要多服的话装多份实例，未来可能会适配（插件目录复制一份、改配置即可）。

### 9. UI 截图里的数据是假的吗？

那是演示数据，用来展示界面形态。真实数据来自你的 RCON 连接与服务端目录扫描。
