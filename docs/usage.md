# 使用指南

[返回 README](../README.md) · [界面效果](gallery.md) · [配置详解](configure.md) · [常见问题](faq.md)

从零到能用的完整流程，以及两种部署形态的取舍。

## 一、服务端开 RCON

编辑服务端根目录的 `server.properties`：

```properties
enable-rcon=true
rcon.port=25575
rcon.password=你的密码
```

改完重启服务端。这是插件唯一必需的服务端改动 —— 不装模组、不改服务端本体。

## 二、插件侧配置

打开 WebUI「设置」页，填下面这些就能跑：

| 配置 | 填什么 |
|---|---|
| `rcon_host` / `rcon_port` / `rcon_password` | 与服务端 `server.properties` 保持一致；同机部署时 host 填 `127.0.0.1` |
| `admin_ids` | 管理员 ID 列表，拥有全部权限（含危险命令）；群聊填 QQ 号，WebChat 填昵称 |
| `server_dir` | 服务端根目录（`logs/`、`mods/` 所在的那一层）。物品词典与知识库依赖它；保存时会做结构校验 |

## 三、两种部署形态

| 能力 | 同机部署 | 异地 RCON 模式 |
|---|---|---|
| 前置条件 | 能读到服务端目录 | 只需映射 RCON 端口 |
| 自然语言指令 / 发物品 / 踢人 / 广播 | ✅ | ✅ |
| 物品词典 · 配方查询 | ✅ | ✗ 按设计禁用 |
| 知识库 | ✅ | ✗ 按设计禁用 |
| 事件播报 · 版本探测 · 进程指标 | ✅ | ✗ 按设计禁用 |

> 异地模式下 WebUI 会把不可用的区块磨砂蒙住并写明原因，不会静默失败。

## 四、在聊天平台用 `mcs` 指令组

在 AstrBot 的聊天平台里发（不是在游戏里输入；前缀跟随 AstrBot 唤醒词设置）：

```
mcs 绑定 <游戏名>        绑定自己 → 游戏名（之后工具可省略玩家名）
mcs 解绑 / mcs 查询
mcs 喊话 <内容>          带昵称转发到服务器聊天栏
mcs 全屏喊话 <内容>      全屏 title 显示给所有人（管理员）
mcs 状态                  mspt / tps / 在线人数 / 运行时长 / 内存 / CPU
mcs 踢人 <玩家> [理由]    （管理员）
mcs 封禁 <玩家> [理由]    （管理员）
mcs 解封 <玩家>           （管理员）
mcs 封禁列表               （管理员）
mcs 帮助                  查看全部用法
```

## 五、用自然语言下任务

插件装好后直接对 AI 说话即可：

| 你说 | AI 调用的工具 |
|---|---|
| 给 Steve 发一把钻石剑 | `mc_give_item` |
| 把天气设成雷雨 | `mc_execute_command` |
| 现在谁在线？ | `mc_list_players` |
| 黄铜锭的 ID 是什么 | `mc_search_item` |
| 帮我满配一把 M4A1 | `mc_workflow`（走多 Agent 流水线） |

复杂模组任务（数值计算、满配枪械、复杂 NBT、批量指令）交给 `mc_workflow`，它会把任务拆给 分类 → 模板判断 → 前瞻建库 → 实现 → 纠错 五个 Agent；简单任务直接调单工具即可，不必绕流水线。

## 六、权限策略

命令工具（执行指令 / 发物品 / 广播）受闸门保护，两种策略：

| 策略 | 行为 |
|---|---|
| **白名单**（默认） | 非管理员完全不能使用命令工具 |
| **黑名单** | 所有人都能用，但 `stop` / `op` / `ban` / `kick` / `whitelist` 等危险命令与权限等级 ≥ 3 的管理命令仍仅管理员可用 |

喊话、状态、查询、绑定这类插件自带功能不受策略影响（想限制喊话请改「喊话对全员开放」）。
被闸门拦住时返回的是终局结论，并附带会话级闩锁，避免 AI 反复换参数硬试。

## 七、事件播报与聊天桥接

开启「服务器事件转发」后，玩家进出 / 聊天 / 死亡 / 成就 / 指令六类事件会推送到指定会话。
目标会话格式为 `平台ID:消息类型:会话ID`，也支持 `私聊:123456789`、`群聊:987654321` 简写；
在 WebUI 里点选类型并填号码即可自动生成。

桥接是反向的：游戏内打 `!123` 就能把内容转发到指定会话（`!` 是默认触发符号，可改；留空表示转发全部聊天）。
推荐在目标会话里直接发 `mcs 桥接` 自动绑定。
