## 补丁 1【必改】静默成功命令白名单 —— 否则广播全部误报失败

### 事实

- **`tellraw` 成功时返回空字符串。** 实测日志：
  ```
  [astrbot_plugin_Scintilla_MC_Server_Control.main:1558]: 反馈发送完成，返回: ''
  ```
- `core/workflow.py:599-600`：`_is_success_out("")` → `False`
- 实施单 §八 要求 `mc_broadcast` / `mcs_say` / `mcs_title_cmd` 「检查服务端错误文本」
- 而 `_send_feedback`（`main.py:1557`）**本身也是 tellraw**

### 照实施单直译会发生什么

```
tellraw 成功 → 空输出 → 判定 failed → 广播报「失败」
_send_feedback 自身走失败分支 → 连反馈都发不出去（自噬）
```

### 必须补的规则

判定空输出前，先查该命令是否**设计上就静默**：

| 类别 | 空输出 + 边界已确认 | 说明 |
| --- | --- | --- |
| 静默幂等<br>`tellraw` `say` `title` `time` `weather` `gamerule` `difficulty` `gamemode` | `success` | 这些命令成功时本就不回文本 |
| 非幂等<br>`give` `summon` `effect` `xp` `item` `fill` `clone` `function` `setblock` | `unknown` | 无法确认副作用是否落定 |
| 其他未知 | `unknown` | 保守兜底 |

实施单 §三「success：命令类型允许空响应，且 RCON 已确认完整边界」方向正确，
但**必须给出白名单**，否则实现者只能自由发挥——这正是最容易翻车的地方。

### 对照测试

- `tellraw @a {"text":"hi"}` + 空输出 → 断言 `success`（**不是** failed）
- `give Steve diamond 1` + 空输出 → 断言 `unknown`
- **删掉白名单 → 广播测试必须失败**

## 补丁 2【必改】拆开两个长得很像的报错

实施单 §三 把 `Unknown or incomplete command` 列入 `syntax_error`。这条**需要拆**：

| 服务端原文 | 真实语义 | 应归 |
| --- | --- | --- |
| `Unknown or incomplete command, see below for error` | 语法/参数写错（命令本身存在） | `syntax_error`（可重试） |
| `Unknown command. Type "/help" for help.` | **该命令在此服务端不存在**（模组没装 / 版本不支持） | `failed`（**重试徒劳**） |

两者只差几个词，语义相反。若都归 `syntax_error`，会对「模组命令不存在」白白重试一轮，
再报一次同样的错——浪费一次 LLM 调用，还污染纠错器的记录。

### 对照测试

- `Unknown command. Type "/help" for help.` → 断言 `failed`，`retryable=False`
- `Unknown or incomplete command` → 断言 `syntax_error`

## 补丁 3【必改】版本未知时，得给用户一个「手动声明」的出口

### 事实

- `main.py:2485`：异地 RCON 模式（`remote_rcon_mode=true`）下**读不到服务端文件**，
  版本探测**显式返回空**
- 实施单 §六 要求：版本未知时「复杂 NBT、物品组件、附魔命令不要直接执行；**必须要求配置版本**」

### 问题

实施单**没有给这个「配置版本」的入口**。

照直做 → 所有异地部署的用户，所有附魔 / NBT 请求**一律被拒**，而且**没有任何办法解除**。
这是功能性倒退。

### 必须补的

新增设置项（建议命名）：

```
server_version_override   # 例 "1.20.1"；留空 = 自动探测
item_syntax_override      # legacy_nbt | components | auto
```

- 优先级：**手动声明 > 文件探测 > 未知**
- 探测失败**且**未手动声明时，才按实施单 §六 降级
- 这**不违反**约束 4「不得猜测」——手动声明是**用户显式提供的事实**，不是猜
- WebUI 设置页要可见提示：
  「当前服务端版本未知，含 NBT 的请求将被拒绝；请填写版本」

### 对照测试

- 远程模式 + 未声明版本 + 附魔请求 → 断言拒绝
- 远程模式 + 声明 `1.20.1` + 附魔请求 → 断言放行，且用 legacy NBT
